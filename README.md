# 🏦 Banking Transaction Management System (Web)

A web-based banking application that allows users to securely manage accounts and perform transactions like deposit, withdrawal, and transfer.

---

## 🎯 Project Goal
To design and build a secure, scalable banking system that demonstrates:
- Backend development using Spring Boot
- Secure authentication using JWT
- Transaction management with ACID principles
- Clean architecture suitable for SDE-1 roles

---

## 🧩 Core Features
- User Registration & Login
- Secure JWT Authentication
- Account Balance Management
- Deposit, Withdraw & Transfer Money
- Transaction History
- Role-based Access Control

---
